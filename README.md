# MetaSense IoT

A one-page website for an IoT system that monitors patients with metabolic
syndrome. Made with HTML and CSS for Seminar #3 of the Web Development elective.

## Sections

- Header with the system name and the navigation menu
- Introduction
- Patient dashboard with 5 parameters
- Sensor cards with name, value, unit and status
- Patient information and monitoring status
- Alerts with normal and abnormal examples
- Footer with system information and contacts

## Files

```
index.html      the page
style.css       the stylesheet
images/         sensor icons
```

All patient data on this page is sample data.
