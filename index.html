Introduction

MetaSense IoT is a system for monitoring patients with metabolic syndrome. Sensors on the patient measure body temperature, blood glucose, heart rate, blood pressure and ECG, and send the values to the server every few minutes. This page shows the last measurements and marks the values that are not normal.
